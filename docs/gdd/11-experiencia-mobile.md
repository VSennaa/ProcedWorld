# 11 — Experiência mobile

## Decidido
- Cliente para celular; o servidor faz todo o processamento (ADR-0001).
- BYOK: o jogador informa a API key e o resto é automático.

## Proposta
- Sessões de 2 a 10 minutos: relatório do turno primeiro, ações principais com poucos toques.
- Notificações: início de turno, gatilhos do Mandato, eventos maiores da Entropia.
- Onboarding: informar a chave → teste de validade → teto de custo diário → criar civilização → jogar.
- Indicador claro do custo de IA consumido.

## Perguntas abertas
- Android primeiro? Cliente web/desktop para testes?
- Orientação de tela (retrato ou paisagem)?
