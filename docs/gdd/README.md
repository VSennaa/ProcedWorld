# GDD — Game Design Document

> **Fase 0.** Cada pilar em seu próprio arquivo, desenvolvido numa branch `docs/gdd/<pilar>`.
> Cada arquivo tem: **Decidido**, **Proposta** (rascunho do agente, aguardando aprovação) e
> **Perguntas abertas**. Nada sai de "Proposta" sem o usuário aprovar.

## Pilares de design

1. **Sociedade viva, não placar.** O objetivo é ver a própria sociedade se desenvolver e atravessar
   eras; não existe vitória obrigatória.
2. **Sistemas que conversam.** Clima, economia, população, tecnologia, crenças e diplomacia
   influenciam uns aos outros; nenhuma mecânica é isolada.
3. **O mundo não espera.** Governadores, bots e a Entropia mantêm o mundo em movimento.
4. **IAs com motivo.** Toda decisão de bot é explicável pelo estado e pela história.
5. **Profundidade em sessões curtas.** Pensado para celular: decisões significativas em poucos minutos.
