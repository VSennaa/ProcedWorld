# 05 — Tecnologia

## Decidido
- A Entropia pode fazer tecnologias "surgirem" como eventos.

## Proposta
- Árvore de base em dados (catálogo), mais **descobertas emergentes**: a Entropia propõe uma descoberta
  a partir de condições (recursos, eventos, cultura) e ela entra como template validado.
- Tecnologias podem ser perdidas em colapsos e redescobertas.

## Perguntas abertas
- Árvore fixa, árvore com ramos aleatórios por mundo, ou totalmente emergente?
- O que acontece quando a árvore termina num jogo infinito?
