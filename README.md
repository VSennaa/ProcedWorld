# ProcedWorld

4X por turnos em tiles hexagonais, no espírito de *Civilization*, com **ciclo infinito**: não há vitória
obrigatória — o objetivo é desenvolver sua sociedade enquanto o mundo continua vivo.

- Civilizações de jogadores e bots num mundo persistente, com servidor autoritativo e auto-hospedável.
- **Governadores**: bots que o jogador configura (Mandato) para decidir por ele.
- **Entropia**: IA diretora de eventos procedurais (clima, descobertas, incidentes, revoltas).
- Diplomacia entre bots baseada em histórico e estado, não em texto solto.
- Motor determinístico: a IA propõe, o motor decide.
